Smart File Renamer

Smart File Renamer is a Windows application that makes it easy to rename multiple files quickly and safely.

Features

  • Rename multiple files at once
  • Preview changes before renaming
  • Custom search and replacement rules
  • Prefixes and suffixes
  • Numbering
  • Uppercase and lowercase conversion
  • Undo previous rename operations
  • English and Spanish interface
